## ⚙️ Engineering & Calculation Model

1. **Gross Envelope Surface Area:**
   Calculates sidewalls, endwalls, gable end triangles, and roof pitch slope expansion ($2:12$ to $8:12$ pitch).
2. **True Board-Foot Volume:**
   $$\text{Total Board Feet} = \text{Surface Area (sq ft)} \times \text{Foam Thickness (inches)}$$
3. **Chemistry & R-Value Sizing:**
   * **Closed-Cell (2.0 lb/cu ft):** R-6.8/in. Class II vapor barrier, stops condensation sweating on metal sheeting, adds 250% racking shear strength.
   * **Open-Cell (0.5 lb/cu ft):** R-3.7/in. High expansion, interior soundproofing.
4. **Chemical Drum Sets:**
   Calculates 55-gallon chemical drum set requirements (~4,500 bd ft yield for closed-cell vs ~16,000 bd ft for open-cell).
